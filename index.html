AI 生成內容與虛構性質

STARWAVE 中由 AI 生成或模擬的直播聊天室、 論壇、SNS、WAVELINK、角色反應、輿論、 新聞式貼文、流言、角色言行與其他內容， 皆屬遊戲中的虛構模擬，不代表真實事實、 真實新聞、證據、專業意見、真人聲明， 也不代表 STARWAVE、開發者、模型供應商 或任何現實人物的立場。

可能出現的不適與爭議內容

依玩家輸入、角色設定、黑粉強度、 社群模式與所選模型不同， AI 可能生成錯誤、矛盾、誇張、具爭議、 不當、冒犯性或令人不適的內容。 黑粉強度 75%～100% 可能出現較大量負面評論、 炎上、惡意猜測與高壓社群內容。

玩家輸入、匯入內容與禁止用途

玩家自行負責輸入內容、匯入角色卡、 Lorebook、圖片、文字與其他素材， 以及自行選擇的第三方模型與 API。 請勿利用本模擬器進行違法活動、惡意騷擾、 冒充、詐騙、誹謗、仇恨攻擊或傷害真人。 請勿將遊戲生成的虛構貼文、角色言論、 傳聞、事件或其他輸出當成真實資訊對外散布， 尤其不得用來冒充真人、捏造現實事件、 誹謗、歧視、騷擾、威脅或傷害現實中的個人或群體。

模擬金錢

STARWAVE 中的打賞、會員收入、商店支出、 生活費及其他金錢數字皆為遊戲模擬， 不涉及真實金錢交易，也不構成財務、 投資或商業建議。

圖片與素材來源

STARWAVE 內建圖片素材由開發者自行使用 生成式 AI 製作。使用者自行上傳、匯入或替換的圖片， 以及其他第三方素材，不屬於此前述聲明範圍； 相關素材之使用權與責任由提供者自行確認。 若未來 STARWAVE 使用其他來源的內建素材， 本項說明會依實際素材來源同步更新。

隱私、API 與資料傳輸

STARWAVE 以本機保存為主要設計方向， 並提供可選的跨裝置同步。 API Key 不包含在一般備份或跨裝置同步資料中。 使用雲端 LLM 時，為完成請求所必要的提示詞、 上下文與 API Key 會依實際架構傳送至 API 供應商； 若請求經 STARWAVE Proxy，資料也會經該服務轉送。 第三方模型與 API 的資料處理仍受各供應商政策約束。

服務限制與使用責任

STARWAVE 僅提供前端介面與模擬工具， 不保證服務永遠可用、完全正確、完全安全或完全無誤。 第三方 AI 模型、API、登入、同步或其他外部服務 可能因供應商政策、規格調整、服務中斷或其他因素 而改變或停止使用，相關情況不由 STARWAVE 控制。
